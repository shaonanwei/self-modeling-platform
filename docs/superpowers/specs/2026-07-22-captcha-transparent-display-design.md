# 登录验证码透明展示设计

## 目标

登录页验证码以图片本身作为视觉主体，不再显示白色卡片背景，也不在鼠标悬停或键盘聚焦时显示“换一个”提示。

## 设计

- 保留现有按钮元素与 `refreshCaptcha` 点击事件，用户仍可点击验证码刷新。
- 移除验证码按钮的背景、边框、阴影和内边距，图片直接显示。
- 删除悬停提示的模板节点和相关样式，并移除不再使用的刷新图标依赖。
- 保留加载状态、固定尺寸、移动端尺寸和键盘焦点轮廓。
- 不修改验证码接口、登录校验或表单提交逻辑。

## 验证

- 静态测试确认模板中不再包含 `captcha-refresh-hint` 和“换一个”提示。
- 静态测试确认验证码按钮无背景、边框、阴影和内边距。
- 前端构建通过。
- 浏览器验证登录页无白底、无悬停提示，点击验证码仍会刷新图片。
